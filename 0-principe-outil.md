# 12/11/2026 Formation sur l'outil d'import du Gretia

L'outil d'import n'est pas un outil d'import, mais presque !  
C'est un outil de pré-import : sa vocation est de rendre compatible n'importe quel tableur au format GeoNature afin de permettre son import final.

# Principe de l'outil import
1. [Importer un fichier CSV dans l'outil](./1-import%20CSV.md)
1. [Mapper (= faire correspondre) les champs du fichier vers ceux de GeoNature](./2-mappage.md)
1. [Passer sur chacuns des champs mappés pour vérifier leurs valeurs en correspondance avec ce que GeoNature peut attendre](3-verifications.md)
1. [(optionnel) Vérifier les observateurs](4-observateurs.md)
1. Vérifier les champs obligatoires non présents dans le fichiers
1. [Vérifier la taxonomie](./6-taxonomie.md)
1. [Vérifier ou geolocaliser les données](./5-localisation.md)
1. [Vérifier les doublons](7-doublon.md)
